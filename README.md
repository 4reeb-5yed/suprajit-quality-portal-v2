# Suprajit Quality Portal (V2)

An edge-deployed, hyper-optimized Quality Management System (QMS) designed specifically for isolated Windows Factory environments. The portal securely indexes, parses, and serves Excel quality reports generated by factory machines using a robust Full-Text Search (FTS5) engine.

## Architecture
This application was intentionally designed to operate without Docker, without Cloud infrastructure, and without heavy database servers (like PostgreSQL) to ensure 100% reliability on a single, offline factory Windows PC.

* **Backend:** Python Flask
* **Production Server:** Waitress (WSGI Multi-threaded)
* **Database:** SQLite (Configured in WAL mode for high-concurrency read/writes)
* **Search Engine:** SQLite FTS5 (Full-Text Search) + Regex Metadata Extraction
* **Deployment:** PyInstaller (Standalone .exe) + NSSM (Native Windows Background Service)

## Key Features
* **N-1 Ingestion Engine:** Automatically processes files from the *previous day* to mathematically eliminate Windows File-Lock crashes caused by actively writing factory machines.
* **Intelligent Deduplication:** Uses SHA-256 hashing and FTS indexing to ensure duplicate reports are never ingested.
* **Developer Repair Tools:** Includes a built-in web dashboard for simulating ingestion runs (Dry Run) and forcing historical syncs.
* **System Telemetry:** Automated heartbeat emails sent to the development team with system health and error logs.
* **Zero-Touch Setup:** Auto-generates the database and a default administrator account on first boot, enforcing a secure Setup Wizard.

## Local Development Setup

1. **Clone the repository:**
`ash
git clone https://github.com/4reeb-5yed/suprajit-quality-portal-v2.git
cd suprajit-quality-portal-v2
`

2. **Create a virtual environment and install dependencies:**
`ash
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
`

3. **Run the application locally:**
`ash
python web_server.py
`
The portal will be available at http://localhost:5000.

## Compiling for Production (Client Handoff)

To package the entire Python ecosystem, Waitress server, and web application into a single standalone Windows Executable:

1. Run the build script:
`ash
.\build.bat
`
2. The final compiled package will be generated at dist/SuprajitQualityPortal/.
3. Hand that folder to the client. The client runs install_service.bat as Administrator to register the executable as a background Windows Service.
